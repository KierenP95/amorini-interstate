Review & Send Booking Request
1

Create a new scenario in Make

Log in to Make.com → click Create a new scenario. Search for the Webhooks app and choose Custom webhook as your trigger module.

2

Add the webhook trigger & copy the URL

Click Add to create a new webhook. Give it a name like Amorini Booking Request. Make will generate a unique URL — copy it and paste it into the Webhook URL field at the top of this page.

3

Determine the data structure

Click Re-determine data structure in Make, then submit a test booking from this page (any carrier except Mainfreight). Make will map all the fields automatically. You'll see these fields arrive:

jobRef customerName deliveryAddress pickupDate deliveryDate cbm cargoType freightType carrier carrierEmail notes sentFrom emailBody
4

Add a Gmail (or SMTP) module to send the email

After the webhook trigger, add a Gmail → Send an Email module (or use SMTP if you prefer). Connect it to bookings@amorinilogistics.com.au. Map the fields like this:

To: {{carrierEmail}} Subject: Delivery Booking Request — {{jobRef}} — {{deliveryAddress}} From: bookings@amorinilogistics.com.au Body: {{emailBody}}
5

Update the carrier email addresses in this file

Open this HTML file in a text editor. Find the three data-email="PLACEHOLDER_..." values on the carrier radio buttons and replace them with the real email addresses for Martin, Sam Jackman, and Andrew. Save the file.

data-email="PLACEHOLDER_MARTIN@..." → real email data-email="PLACEHOLDER_SAM@..." → real email data-email="PLACEHOLDER_ANDREW@..." → real email
6

(Optional) Add a Google Sheets module to log bookings

After the Gmail module, add a Google Sheets → Add a Row module. Map each field to a column in your warehouse booking log sheet. This gives the warehouse team a live view of all upcoming deliveries with CBM and cargo details.

7

Turn on the scenario & test

Flip the scenario to ON. Submit a real test booking from this page. Check that the email arrives at the carrier address and that the row appears in your Google Sheet. You're live.

1

Create a Google Cloud project

Go to console.cloud.google.com and sign in with your Google account. Click Select a project → New Project. Name it something like Amorini Logistics and click Create.

2

Enable the Places API

In the left menu go to APIs & Services → Library. Search for Places API and click Enable. Also enable Maps JavaScript API while you're there — both are needed.

3

Create an API key

Go to APIs & Services → Credentials → Create Credentials → API Key. Google will generate a key starting with AIzaSy… — copy it.

4

Restrict the key (recommended)

Click Edit API key. Under Application restrictions, choose HTTP referrers and add the URL where you host this file (e.g. your Netlify domain). Under API restrictions, restrict it to Maps JavaScript API and Places API only. This stops anyone else from using your key.

5

Paste the key into this tool

Copy your API key and paste it into the Google Maps API Key field at the top of this page, then click Save. The address field will immediately gain autocomplete suggestions as you type.

6

Billing & free tier

Google requires a billing account to be attached, but the Places Autocomplete API includes a generous free monthly credit (~$200 USD). At roughly $0.0028 per session, you'd need to make around 70,000 address lookups per month before paying anything. For internal warehouse use, you'll almost certainly stay free.
