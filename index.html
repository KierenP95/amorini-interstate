Review & Send Booking Request
1

Create a new scenario in Make

Log in to Make.com → click Create a new scenario. Search for the Webhooks app and choose Custom webhook as your trigger module.

2

Add the webhook trigger & copy the URL

Click Add to create a new webhook. Give it a name like Amorini Booking Request. Make will generate a unique URL — copy it and paste it into the Webhook URL field at the top of this page.

3

Determine the data structure

Click Re-determine data structure in Make, then submit a test booking from this page. Make will map all the fields automatically.

jobRefcustomerNamedeliveryAddresspickupDatedeliveryDatecbmcargoTypefreightTypecarriercarrierEmailnotesemailBody
4

Add a Gmail module to send the email

After the webhook trigger, add a Gmail → Send an Email module. Map the fields:

To: {{carrierEmail}} Subject: Delivery Booking Request — {{jobRef}} — {{deliveryAddress}} Body: {{emailBody}}
5

Update carrier email addresses

Open this HTML file in a text editor. Find the three data-email="PLACEHOLDER_..." values and replace with real addresses.

6

Turn on the scenario & test

Flip the scenario to ON. Submit a real test booking. Check that the email arrives and the Google Sheet row appears.

1

Create a Google Cloud project

Go to console.cloud.google.com → New Project → name it Amorini Logistics.

2

Enable the Places API

APIs & Services → Library → search Places API → Enable. Also enable Maps JavaScript API.

3

Create & restrict an API key

Credentials → Create Credentials → API Key. Restrict to your Netlify domain and to Places + Maps JavaScript APIs only.

4

Paste the key into this tool

Paste your key into the Google Maps API Key field at the top and click Save. Autocomplete activates immediately.
